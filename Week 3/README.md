Sales Performance Dashboard | Power BI

## Project Overview
This project involved creating an interactive Sales Performance Dashboard using Microsoft Power BI. The dashboard was designed to provide an overview of sales performance by visualizing key business metrics and exploring revenue across different categories, regions, order statuses and months.

## Dashboard Preview

![Sales Performance Dashboard](dashboard.png)

## Key Performance Indicators (KPIs)
- *Total Net Sales:* 15.02bn
- *Total Profit:* ₦4.94bn
- *Profit Margin:* 33%
- *Average Total Cost:* 1.74M
- *Total Orders:* 10K

## Dashboard Visualizations
The dashboard features the following visualizations:

- *Revenue by Category:* Shows revenue generated across different product categories.
- *Revenue by Region:* Compares revenue generated across different regions.
- *Revenue by Orders Status:* Displays the distribution of orders by their status.
- *Revenue by Month and Year:* Shows monthly revenue trends across different years.

## Interactive Features
- Category filter
- Year filter

These filters allow users to interact with the dashboard and explore sales performance based on selected categories and years.
