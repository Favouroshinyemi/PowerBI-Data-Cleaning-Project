# WEEK 8: DATA MODELLING IN POWER BI

## Overview
In Week 8 of my Data Analytics learning journey, I explored Data Modelling in Power BI and learned how to structure tables, establish relationships and create an effective data model for analysis.

Data modelling is an important part of Power BI because it helps organize data and ensures that different tables work together to support accurate reporting and visualization.

## Topics Covered

### 1. Types of Data Models
I learned about three types of data models:

- *Flat Table:* A model where all information is stored in one table.
- *Star Schema:* A model consisting of one fact table connected to multiple dimension tables.
- *Snowflake Schema:* A model where dimension tables are further connected to other related dimension tables.

### 2. Cardinality
Cardinality describes the type of relationship between tables.

The four types I learned are:

- One-to-One (1:1)
- One-to-Many (1:*)
- Many-to-One (*:1)
- Many-to-Many (:)

### 3. Cross-Filter Direction
Cross-filter direction determines how filters move between related tables.

- *Single:* Filters flow in one direction.
- *Both:* Filters flow in both directions.

### 4. Fact Tables and Dimension Tables

*Fact Table:*
A fact table contains transactional information, such as sales amounts, quantities and transactions.

*Dimension Tables:*
Dimension tables contain descriptive information used to analyze the data, such as customer details, product information and dates.

### 5. Primary Keys and Foreign Keys

- *Primary Key:* A column that uniquely identifies each record in a table.
- *Foreign Key:* A column used to establish a relationship between tables.

### 6. Practical Application: Building a Data Model

I applied what I learned by creating a Star Schema data model in Power BI.

My model consisted of:

- Sales – Fact Table
- Customers – Dimension Table
- Products – Dimension Table
- Date – Dimension Table

I established relationships between the fact table and the dimension tables using their related key columns.

This helped me understand how different tables connect and how a well-structured data model supports effective data analysis.

## Key Takeaways
This week's lesson helped me understand that data modelling goes beyond connecting tables. It involves organizing data, defining relationships and ensuring that information flows correctly between tables.

I now have a better understanding of how Star Schemas, cardinality, cross-filter directions, primary keys and foreign keys work together in Power BI.

## Tools Used
- Microsoft Power BI
