# Week 7: Introduction to Power BI & Data Cleaning

## Project Overview
Week 7 marked the beginning of my Power BI learning journey. I was introduced to Power BI and learned how it is used to connect, transform, model, and visualize data.

## What I Learned
During this week, I covered the following topics:

- Introduction to Microsoft Power BI.
- The three main views in Power BI Desktop: Report View, Data View, and Model View.
- Common cloud data sources used in Power BI.
- Introduction to data models.
- Understanding primary keys and foreign keys.

## Practical Exercise: Data Cleaning with Power Query

I had the opportunity to practise data cleaning using Power Query Editor.

I worked on four different tables:

1. Customers
2. Date
3. Products
4. Sales

I cleaned and prepared the four tables to make the data more organized and suitable for further analysis and data modelling.

## Tools Used

- Power Query Editor
